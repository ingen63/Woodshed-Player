# Mutants excluded with a reason (#11/AK2), read by app/tool/mutants_run.dart (make mutants).

# Every not detected mutant is either killed by a test or excluded here; there is no target score.
# An entry is «<file> | <mutator> | <source line>», optionally «| <column>» when the line holds the
# operator more than once (fields separated by « | »), and needs a reason in the comment block above it,
# starting with one of the two allowed kinds (docs/TESTS.md «Mutationstests (#11)»):
#   # gleichwertig: <why the result is the same for every input>
#   # Grenzfall: <why only an exact equality or a rounding tolerance changes>
# Entries right below each other share the reason; an empty line ends it. An entry without a reason
# stops the run (exit code 2). The source line is compared without the line number and with runs of
# whitespace squashed, so the entry survives changes above it; if the line itself changes, the
# mutant shows up again and is judged anew. A full run lists entries that no longer match anything.
